# PS5 DirStat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A PS5 payload that scans the file system at low priority and shows disk usage in a web panel: a size-sorted tree with bars and a squarified treemap.

**Architecture:** C payload (PS5 Payload SDK). A scan thread walks `/` into a compact in-memory tree (node array + string pool), sorted and summed at the end, swapped in under a mutex and written as a binary snapshot. A one-request-per-connection HTTP server serves two pages (current and legacy) that share one ES5 script for the tree and one for the treemap.

**Tech Stack:** C11, `prospero-clang` (PS5 Payload SDK at `/opt/ps5-payload-sdk`), SQLite amalgamation (read-only `app.db` check for the Media tab shortcut, copied from ps4mount), ES5 JavaScript, Node 22 `node:test` for the treemap test, bash.

**Spec:** `docs/superpowers/specs/2026-10-14-ps5-dirstat-design.md`

## Review Focus

1. File names with quotes, control characters or invalid UTF-8 (common on exFAT drives): JSON must stay valid, names shown with U+FFFD. Pinned in Task 1 (`buf_test.c`).
2. Entries that vanish or cannot be stat'ed between `readdir` and `fstatat` (files deleted during the scan, directories with `r` but no `x`): node gets `err`, scan goes on. Pinned in Task 3 (`noexec/` case).
3. A `last.bin` truncated or corrupted by a crash or power loss, including loops in sibling links: rejected, panel shows "No scan yet", no hang. Pinned in Task 4.
4. The browser holding ids from an older tree after a rescan: 409, then the panel reloads from the root. Pinned in Task 7 (`http_test.c`).
5. A mount holding real data with a skipped type (for example `/user` being `nullfs` on some firmware): totals would be too small. Pinned in Task 3 (every mount and its type is logged) and Task 10 (console total compared with the used space of each disk).

```c
#pragma once

#include <stddef.h>
#include <stdint.h>

typedef struct {
    uint8_t *data; /* always NUL terminated after a put */
    size_t len, cap;
} buf_t;

void buf_put(buf_t *b, const void *data, size_t len);
void buf_printf(buf_t *b, const char *fmt, ...) __attribute__((format(printf, 2, 3)));
void buf_free(buf_t *b);
/* s as a JSON string with its quotes. Control characters are escaped and bytes that are
 * not valid UTF-8 become U+FFFD, so any file name gives valid JSON. */
void buf_json_str(buf_t *b, const char *s);

/* A string literal without its NUL. */
#define BUF_LIT(b, s) buf_put((b), (s), sizeof(s) - 1)
```

```c
/* SPDX-License-Identifier: GPL-3.0-or-later
 * Copyright (C) 2026 gasb07
 * Growing byte buffer and JSON string output. */
#include "buf.h"

#include <stdarg.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

void buf_put(buf_t *b, const void *data, size_t len) {
    if (b->len + len + 1 > b->cap) {
        size_t cap = b->cap ? b->cap : 256;
        while (cap < b->len + len + 1)
            cap *= 2;
        uint8_t *g = realloc(b->data, cap);
        if (!g)
            return; /* the output is cut, never corrupted */
        b->data = g;
        b->cap = cap;
    }
    memcpy(b->data + b->len, data, len);
    b->len += len;
    b->data[b->len] = 0;
}

void buf_printf(buf_t *b, const char *fmt, ...) {
    char tmp[1024];
    va_list ap;
    va_start(ap, fmt);
    int n = vsnprintf(tmp, sizeof(tmp), fmt, ap);
    va_end(ap);
    if (n > 0)
        buf_put(b, tmp, (size_t)n < sizeof(tmp) ? (size_t)n : sizeof(tmp) - 1);
}

void buf_free(buf_t *b) {
    free(b->data);
    memset(b, 0, sizeof(*b));
}

/* Length of the valid UTF-8 sequence at p, 0 when it is not one. */
static int utf8_len(const unsigned char *p) {
    unsigned c = p[0];
    int n = c >= 0xc2 && c <= 0xdf ? 2 : c >= 0xe0 && c <= 0xef ? 3 : c >= 0xf0 && c <= 0xf4 ? 4 : 0;
    for (int i = 1; i < n; i++)
        if ((p[i] & 0xc0) != 0x80)
            return 0;
    if ((c == 0xe0 && p[1] < 0xa0) || (c == 0xed && p[1] >= 0xa0) || (c == 0xf0 && p[1] < 0x90) ||
        (c == 0xf4 && p[1] >= 0x90))
        return 0; /* overlong, surrogate or past U+10FFFF */
    return n;
}

void buf_json_str(buf_t *b, const char *s) {
    const unsigned char *p = (const unsigned char *)s;
    BUF_LIT(b, "\"");
    while (*p) {
        if (*p == '"' || *p == '\\') {
            char e[2] = {'\\', (char)*p++};
            buf_put(b, e, 2);
        } else if (*p < 0x20) {
            char e[8];
            snprintf(e, sizeof(e), "\\u%04x", *p++);
            buf_put(b, e, 6);
        } else if (*p < 0x80) {
            buf_put(b, p++, 1);
        } else {
            int n = utf8_len(p);
            if (n) {
                buf_put(b, p, (size_t)n);
                p += n;
            } else {
                BUF_LIT(b, "\xef\xbf\xbd");
                p++;
            }
        }
    }
    BUF_LIT(b, "\"");
}
```

```c
/* SPDX-License-Identifier: GPL-3.0-or-later
 * Copyright (C) 2026 gasb07
 * Scanned tree: one node array plus one string pool, and its JSON for the panel. */
#pragma once

#include <stddef.h>
#include <stdint.h>

#include "buf.h"

#define TREE_NONE 0xffffffffu
#define TREE_MAX_BYTES ((size_t)256 << 20)

enum { NODE_FILE, NODE_DIR, NODE_SKIP }; /* NODE_SKIP: a directory that is not entered */

typedef struct {
    uint32_t parent, child, next; /* node indexes, TREE_NONE when absent */
    uint32_t name;                /* offset in the pool */
    uint64_t size;                /* bytes; for a directory, everything below it */
    uint32_t files, dirs;         /* below a directory, all levels */
    uint32_t type;                /* NODE_* */
    uint32_t err;                 /* errno when it could not be read, 0 when it could */
} node_t;

typedef struct {
    node_t *nodes;
    uint32_t n, cap;
    char *pool;
    size_t pool_len, pool_cap;
    size_t max_bytes;     /* cap for nodes + pool; 0 means TREE_MAX_BYTES */
    int64_t time;         /* scan start, unix seconds */
    uint64_t duration_ms; /* scan length */
    uint32_t errors;      /* nodes with err != 0, set by tree_finish */
} tree_t;

/* Adds a node under parent; the first node is the root (parent TREE_NONE). A child always
 * gets a higher index than its parent. Returns the index, or TREE_NONE when the parent is
 * invalid or the memory cap is reached. */
uint32_t tree_add(tree_t *t, uint32_t parent, const char *name, uint32_t type, uint64_t size, uint32_t err);
/* Sums sizes and counts into the directories, sorts children by size (largest first) and
 * counts errors. 0, or -1 when out of memory. */
int tree_finish(tree_t *t);
void tree_free(tree_t *t);
const char *tree_name(const tree_t *t, uint32_t id);
/* Appends the full path of id ("/user/app/x"). */
void tree_path(const tree_t *t, uint32_t id, buf_t *out);
/* JSON for /api/node: the node, its path and ancestors, up to limit children, the rest
 * summed in "others". */
void tree_node_json(const tree_t *t, uint32_t id, uint32_t limit, buf_t *out);
/* JSON for /api/map: up to depth levels below id and max_nodes nodes, picked level by
 * level. Children under 1/1000 of their parent, or past the budget, are merged into one
 * "others" cell. 0, or -1 when out of memory. */
int tree_map_json(const tree_t *t, uint32_t id, int depth, uint32_t max_nodes, buf_t *out);
```

```c
/* SPDX-License-Identifier: GPL-3.0-or-later
 * Copyright (C) 2026 gasb07
 * Scanned tree: one node array plus one string pool, and its JSON for the panel. */
#include "tree.h"

#include <stdlib.h>
#include <string.h>

#define MAX_CHAIN 512 /* deeper than the scan ever goes (256) */

static size_t limit_of(const tree_t *t) { return t->max_bytes ? t->max_bytes : TREE_MAX_BYTES; }

/* Bytes left for one array when the other keeps its size. */
static size_t room(const tree_t *t, size_t other) { return other < limit_of(t) ? limit_of(t) - other : 0; }

uint32_t tree_add(tree_t *t, uint32_t parent, const char *name, uint32_t type, uint64_t size, uint32_t err) {
    size_t len = strlen(name) + 1;
    if ((parent == TREE_NONE) != (t->n == 0) || (parent != TREE_NONE && parent >= t->n))
        return TREE_NONE;
    if (t->n == t->cap) {
        size_t max = room(t, t->pool_cap) / sizeof(node_t), cap = t->cap ? (size_t)t->cap * 2 : 4096;
        if (cap > max)
            cap = max;
        if (cap > 0xfffffff0u)
            cap = 0xfffffff0u;
        if (cap <= t->n)
            return TREE_NONE;
        node_t *g = realloc(t->nodes, cap * sizeof(node_t));
        if (!g)
            return TREE_NONE;
        t->nodes = g;
        t->cap = (uint32_t)cap;
    }
    if (t->pool_len + len > t->pool_cap) {
        size_t max = room(t, (size_t)t->cap * sizeof(node_t)), cap = t->pool_cap ? t->pool_cap * 2 : 65536;
        while (cap < t->pool_len + len)
            cap *= 2;
        if (cap > max)
            cap = max;
        if (cap < t->pool_len + len)
            return TREE_NONE;
        char *g = realloc(t->pool, cap);
        if (!g)
            return TREE_NONE;
        t->pool = g;
        t->pool_cap = cap;
    }
    uint32_t id = t->n++;
    node_t *nd = &t->nodes[id];
    memset(nd, 0, sizeof(*nd));
    nd->parent = parent;
    nd->child = TREE_NONE;
    nd->next = TREE_NONE;
    nd->name = (uint32_t)t->pool_len;
    nd->type = type;
    nd->size = size;
    nd->err = err;
    memcpy(t->pool + t->pool_len, name, len);
    t->pool_len += len;
    if (parent != TREE_NONE) {
        nd->next = t->nodes[parent].child;
        t->nodes[parent].child = id;
    }
    return id;
}

typedef struct {
    uint64_t size;
    uint32_t id;
} ent_t;

static int by_size(const void *a, const void *b) {
    const ent_t *x = a, *y = b;
    if (x->size != y->size)
        return x->size < y->size ? 1 : -1;
    return x->id < y->id ? -1 : x->id > y->id;
}

int tree_finish(tree_t *t) {
    t->errors = 0;
    /* children have higher indexes than their parents: one backward pass sums everything */
    for (uint32_t i = t->n; i-- > 0;) {
        node_t *c = &t->nodes[i];
        if (c->err)
            t->errors++;
        if (c->parent == TREE_NONE)
            continue;
        node_t *p = &t->nodes[c->parent];
        p->size += c->size;
        p->files += c->files + (c->type == NODE_FILE);
        p->dirs += c->dirs + (c->type != NODE_FILE);
    }
    ent_t *v = NULL;
    size_t cap = 0;
    for (uint32_t i = 0; i < t->n; i++) {
        size_t k = 0;
        for (uint32_t c = t->nodes[i].child; c != TREE_NONE; c = t->nodes[c].next) {
            if (k == cap) {
                size_t nc = cap ? cap * 2 : 256;
                ent_t *g = realloc(v, nc * sizeof(*g));
                if (!g) {
                    free(v);
                    return -1;
                }
                v = g;
                cap = nc;
            }
            v[k].size = t->nodes[c].size;
            v[k].id = c;
            k++;
        }
        if (k < 2)
            continue;
        qsort(v, k, sizeof(*v), by_size);
        t->nodes[i].child = v[0].id;
        for (size_t j = 0; j + 1 < k; j++)
            t->nodes[v[j].id].next = v[j + 1].id;
        t->nodes[v[k - 1].id].next = TREE_NONE;
    }
    free(v);
    return 0;
}

void tree_free(tree_t *t) {
    free(t->nodes);
    free(t->pool);
    memset(t, 0, sizeof(*t));
}

const char *tree_name(const tree_t *t, uint32_t id) { return t->pool + t->nodes[id].name; }

void tree_path(const tree_t *t, uint32_t id, buf_t *out) {
    uint32_t chain[MAX_CHAIN];
    int n = 0;
    for (uint32_t i = id; i != TREE_NONE && n < MAX_CHAIN; i = t->nodes[i].parent)
        chain[n++] = i;
    size_t start = out->len;
    for (int k = n - 1; k >= 0; k--) {
        const char *s = tree_name(t, chain[k]);
        if (k < n - 1 && out->len > start && out->data[out->len - 1] != '/')
            BUF_LIT(out, "/");
        buf_put(out, s, strlen(s));
    }
}

static const char *type_name(uint32_t type) {
    return type == NODE_DIR ? "dir" : type == NODE_SKIP ? "skip" : "file";
}

static void node_fields(const tree_t *t, uint32_t id, buf_t *out) {
    const node_t *nd = &t->nodes[id];
    buf_printf(out, "\"id\":%u,\"name\":", id);
    buf_json_str(out, tree_name(t, id));
    buf_printf(out, ",\"size\":%llu,\"files\":%u,\"dirs\":%u,\"type\":\"%s\",\"err\":%u", (unsigned long long)nd->size,
               nd->files, nd->dirs, type_name(nd->type), nd->err);
}

void tree_node_json(const tree_t *t, uint32_t id, uint32_t limit, buf_t *out) {
    BUF_LIT(out, "{");
    node_fields(t, id, out);
    buf_t path = {0};
    tree_path(t, id, &path);
    BUF_LIT(out, ",\"path\":");
    buf_json_str(out, path.data ? (const char *)path.data : "");
    buf_free(&path);
    BUF_LIT(out, ",\"ancestors\":[");
    uint32_t chain[MAX_CHAIN];
    int n = 0;
    for (uint32_t i = t->nodes[id].parent; i != TREE_NONE && n < MAX_CHAIN; i = t->nodes[i].parent)
        chain[n++] = i;
    for (int k = n - 1; k >= 0; k--) {
        buf_printf(out, "%s{\"id\":%u,\"name\":", k == n - 1 ? "" : ",", chain[k]);
        buf_json_str(out, tree_name(t, chain[k]));
        BUF_LIT(out, "}");
    }
    BUF_LIT(out, "],\"children\":[");
    uint32_t shown = 0, more = 0;
    uint64_t more_size = 0;
    for (uint32_t c = t->nodes[id].child; c != TREE_NONE; c = t->nodes[c].next) {
        if (shown < limit) {
            if (shown++)
                BUF_LIT(out, ",");
            BUF_LIT(out, "{");
            node_fields(t, c, out);
            BUF_LIT(out, "}");
        } else {
            more++;
            more_size += t->nodes[c].size;
        }
    }
    buf_printf(out, "],\"others\":{\"count\":%u,\"size\":%llu}}", more, (unsigned long long)more_size);
}

#define MAP_IN 1   /* in the map */
#define MAP_OPEN 2 /* its children were considered */

static void map_emit(const tree_t *t, uint32_t id, const uint8_t *mark, buf_t *out) {
    const node_t *nd = &t->nodes[id];
    buf_printf(out, "{\"id\":%u,\"n\":", id);
    buf_json_str(out, tree_name(t, id));
    buf_printf(out, ",\"s\":%llu,\"t\":\"%s\"", (unsigned long long)nd->size, type_name(nd->type));
    if (mark[id] & MAP_OPEN) {
        int shown = 0;
        uint32_t k = 0;
        uint64_t rest = 0;
        for (uint32_t c = nd->child; c != TREE_NONE; c = t->nodes[c].next) {
            if (mark[c] & MAP_IN) {
                BUF_LIT(out, shown++ ? "," : ",\"c\":[");
                map_emit(t, c, mark, out);
            } else if (t->nodes[c].size) {
                k++;
                rest += t->nodes[c].size;
            }
        }
        if (k) {
            BUF_LIT(out, shown++ ? "," : ",\"c\":[");
            buf_printf(out, "{\"n\":\"\",\"s\":%llu,\"k\":%u,\"o\":1}", (unsigned long long)rest, k);
        }
        if (shown)
            BUF_LIT(out, "]");
    }
    BUF_LIT(out, "}");
}

int tree_map_json(const tree_t *t, uint32_t id, int depth, uint32_t max_nodes, buf_t *out) {
    uint8_t *mark = calloc(t->n, 1);
    uint32_t *q = malloc(sizeof(*q) * ((size_t)max_nodes + 1));
    uint8_t *lvl = malloc((size_t)max_nodes + 1);
    if (!mark || !q || !lvl) {
        free(mark);
        free(q);
        free(lvl);
        return -1;
    }
    /* level by level, so a large first branch cannot use the whole budget */
    uint32_t head = 0, tail = 0, count = 1;
    mark[id] = MAP_IN;
    q[tail] = id;
    lvl[tail++] = 0;
    while (head < tail) {
        uint32_t p = q[head];
        int l = lvl[head++];
        if (l >= depth || t->nodes[p].type != NODE_DIR)
            continue;
        mark[p] |= MAP_OPEN;
        uint64_t min = t->nodes[p].size / 1000;
        for (uint32_t c = t->nodes[p].child; c != TREE_NONE && count < max_nodes; c = t->nodes[c].next) {
            if (!t->nodes[c].size || t->nodes[c].size < min)
                break; /* sorted by size: the rest is smaller */
            mark[c] = MAP_IN;
            q[tail] = c;
            lvl[tail++] = (uint8_t)(l + 1);
            count++;
        }
    }
    map_emit(t, id, mark, out);
    free(mark);
    free(q);
    free(lvl);
    return 0;
}
```

```c
/* SPDX-License-Identifier: GPL-3.0-or-later
 * Copyright (C) 2026 gasb07
 * Walks a directory tree into a tree_t. */
#include "scan.h"

#include <dirent.h>
#include <errno.h>
#include <fcntl.h>
#include <limits.h>
#include <stdlib.h>
#include <string.h>
#include <sys/stat.h>
#include <time.h>
#include <unistd.h>

/* (dev, ino) of files with more than one link, so each is counted once. */
typedef struct {
    uint64_t dev, ino;
} link_key_t;

typedef struct {
    link_key_t *s;
    size_t n, cap; /* cap is a power of two */
} links_t;

static link_key_t *slot(link_key_t *s, size_t cap, uint64_t dev, uint64_t ino) {
    size_t i = (size_t)((dev * 0x9e3779b97f4a7c15ull) ^ (ino * 0xc2b2ae3d27d4eb4full)) & (cap - 1);
    while ((s[i].dev || s[i].ino) && (s[i].dev != dev || s[i].ino != ino))
        i = (i + 1) & (cap - 1);
    return &s[i];
}

/* 1 when seen before, 0 when recorded now, -1 out of memory. */
static int links_seen(links_t *l, uint64_t dev, uint64_t ino) {
    if ((l->n + 1) * 2 > l->cap) {
        size_t cap = l->cap ? l->cap * 2 : 1024;
        link_key_t *s = calloc(cap, sizeof(*s));
        if (!s)
            return -1;
        for (size_t i = 0; i < l->cap; i++)
            if (l->s[i].dev || l->s[i].ino)
                *slot(s, cap, l->s[i].dev, l->s[i].ino) = l->s[i];
        free(l->s);
        l->s = s;
        l->cap = cap;
    }
    link_key_t *k = slot(l->s, l->cap, dev, ino);
    if (k->dev == dev && k->ino == ino && (dev || ino))
        return 1;
    k->dev = dev;
    k->ino = ino;
    l->n++;
    return 0;
}

typedef struct {
    const scan_opt_t *o;
    tree_t *t;
    links_t links;
    char path[PATH_MAX];
    uint64_t entries;
    int status;
} ctx_t;

static int skipped(const ctx_t *c) {
    for (int i = 0; i < c->o->nskip; i++)
        if (!strcmp(c->o->skip[i], c->path))
            return 1;
    return 0;
}

static void tick(ctx_t *c) {
    if (++c->entries % SCAN_TICK)
        return;
    if (c->o->progress)
        c->o->progress(c->o->ctx, c->entries, c->path);
    if (c->o->cancel && *c->o->cancel)
        c->status = SCAN_CANCELLED;
    if (c->o->pause_us)
        usleep(c->o->pause_us);
}

/* Reads directory id, whose path (len bytes) is in c->path, then goes into its
 * subdirectories. The directory is closed before going down: open descriptors never
 * grow with the depth. */
static void walk(ctx_t *c, uint32_t id, size_t len, int depth) {
    int fd = open(c->path, O_RDONLY | O_DIRECTORY | O_NOFOLLOW | O_CLOEXEC);
    DIR *d = fd >= 0 ? fdopendir(fd) : NULL;
    if (!d) {
        c->t->nodes[id].err = errno ? (uint32_t)errno : EIO;
        if (fd >= 0)
            close(fd);
        return;
    }
    for (;;) {
        errno = 0;
        struct dirent *e = readdir(d);
        if (!e) {
            if (errno)
                c->t->nodes[id].err = (uint32_t)errno;
            break;
        }
        if (!strcmp(e->d_name, ".") || !strcmp(e->d_name, ".."))
            continue;
        struct stat st;
        uint32_t type = NODE_FILE, err = 0;
        uint64_t size = 0;
        if (fstatat(dirfd(d), e->d_name, &st, AT_SYMLINK_NOFOLLOW))
            err = (uint32_t)errno; /* gone since readdir, or no search permission */
        else if (S_ISDIR(st.st_mode))
            type = NODE_DIR;
        else if (S_ISREG(st.st_mode)) {
            int seen = st.st_nlink > 1 ? links_seen(&c->links, (uint64_t)st.st_dev, (uint64_t)st.st_ino) : 0;
            if (seen < 0) {
                c->status = SCAN_NOMEM;
                break;
            }
            size = seen ? 0 : (uint64_t)st.st_size;
        } else if (S_ISLNK(st.st_mode))
            size = (uint64_t)st.st_size;
        if (tree_add(c->t, id, e->d_name, type, size, err) == TREE_NONE) {
            c->status = SCAN_NOMEM;
            break;
        }
        tick(c);
        if (c->status != SCAN_OK)
            break;
    }
    closedir(d);
    for (uint32_t ch = c->t->nodes[id].child; ch != TREE_NONE && c->status == SCAN_OK; ch = c->t->nodes[ch].next) {
        if (c->t->nodes[ch].type != NODE_DIR || c->t->nodes[ch].err)
            continue;
        const char *name = tree_name(c->t, ch);
        size_t nl = strlen(name), at = c->path[len - 1] == '/' ? len : len + 1;
        if (depth + 1 >= SCAN_MAX_DEPTH || at + nl + 1 > sizeof(c->path)) {
            c->t->nodes[ch].err = ENAMETOOLONG;
            continue;
        }
        c->path[len] = '/';
        memcpy(c->path + at, name, nl + 1);
        if (skipped(c))
            c->t->nodes[ch].type = NODE_SKIP;
        else
            walk(c, ch, at + nl, depth + 1); /* may move nodes and pool: nothing kept across it */
        c->path[len] = 0;
    }
}

int scan_run(const scan_opt_t *o, tree_t *t) {
    ctx_t c;
    memset(&c, 0, sizeof(c));
    c.o = o;
    c.t = t;
    struct timespec a, b;
    clock_gettime(CLOCK_MONOTONIC, &a);
    t->time = (int64_t)time(NULL);
    size_t len = strlen(o->root);
    if (!len || len >= sizeof(c.path) || tree_add(t, TREE_NONE, o->root, NODE_DIR, 0, 0) == TREE_NONE)
        return SCAN_NOMEM;
    memcpy(c.path, o->root, len + 1);
    walk(&c, 0, len, 0);
    free(c.links.s);
    if (c.status == SCAN_OK && tree_finish(t))
        c.status = SCAN_NOMEM;
    clock_gettime(CLOCK_MONOTONIC, &b);
    t->duration_ms = (uint64_t)((b.tv_sec - a.tv_sec) * 1000 + (b.tv_nsec - a.tv_nsec) / 1000000);
    return c.status;
}
```

```c
/* SPDX-License-Identifier: GPL-3.0-or-later
 * Copyright (C) 2026 gasb07
 * The last scan on disk. */
#include "snap.h"

#include <fcntl.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/stat.h>
#include <unistd.h>

#define SNAP_MAGIC "DIRSTAT"
#define SNAP_VERSION 1

typedef struct {
    char magic[8];
    uint32_t version, node_size;
    uint64_t nodes, pool;
    int64_t time;
    uint64_t duration_ms;
} snap_head_t;

_Static_assert(sizeof(snap_head_t) == 48, "snapshot header layout");

static int write_all(int fd, const void *p, size_t n) {
    const char *c = p;
    while (n) {
        ssize_t w = write(fd, c, n);
        if (w <= 0)
            return -1;
        c += w;
        n -= (size_t)w;
    }
    return 0;
}

static int read_all(int fd, void *p, size_t n) {
    char *c = p;
    while (n) {
        ssize_t r = read(fd, c, n);
        if (r <= 0)
            return -1;
        c += r;
        n -= (size_t)r;
    }
    return 0;
}

int snap_write(const char *path, const tree_t *t) {
    char tmp[1024];
    if ((size_t)snprintf(tmp, sizeof(tmp), "%s.tmp", path) >= sizeof(tmp))
        return -1;
    snap_head_t h;
    memset(&h, 0, sizeof(h));
    memcpy(h.magic, SNAP_MAGIC, sizeof(SNAP_MAGIC));
    h.version = SNAP_VERSION;
    h.node_size = sizeof(node_t);
    h.nodes = t->n;
    h.pool = t->pool_len;
    h.time = t->time;
    h.duration_ms = t->duration_ms;
    int fd = open(tmp, O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (fd < 0)
        return -1;
    int bad = write_all(fd, &h, sizeof(h)) || write_all(fd, t->nodes, sizeof(node_t) * t->n) ||
              write_all(fd, t->pool, t->pool_len);
    bad |= fsync(fd) != 0;
    bad |= close(fd) != 0;
    if (bad || rename(tmp, path)) {
        unlink(tmp);
        return -1;
    }
    return 0;
}

/* Every index in range, parents before children, each node linked once under its own
 * parent (which also rules out loops), names inside the pool. */
static int valid(const tree_t *t) {
    if (!t->pool_len || t->pool[t->pool_len - 1] || t->nodes[0].parent != TREE_NONE)
        return 0;
    uint8_t *seen = calloc(t->n, 1);
    if (!seen)
        return 0;
    int ok = 1;
    for (uint32_t i = 0; ok && i < t->n; i++) {
        const node_t *nd = &t->nodes[i];
        if (nd->name >= t->pool_len || nd->type > NODE_SKIP || (i && nd->parent >= i) ||
            (nd->child != TREE_NONE && nd->child >= t->n) || (nd->next != TREE_NONE && nd->next >= t->n))
            ok = 0;
        for (uint32_t c = nd->child; ok && c != TREE_NONE; c = t->nodes[c].next) {
            if (c >= t->n || seen[c] || t->nodes[c].parent != i)
                ok = 0;
            else
                seen[c] = 1;
        }
    }
    for (uint32_t i = 1; ok && i < t->n; i++)
        ok = seen[i];
    free(seen);
    return ok;
}

int snap_read(const char *path, tree_t *t) {
    memset(t, 0, sizeof(*t));
    int fd = open(path, O_RDONLY);
    if (fd < 0)
        return -1;
    struct stat st;
    snap_head_t h;
    tree_t r;
    memset(&r, 0, sizeof(r));
    if (fstat(fd, &st) || read_all(fd, &h, sizeof(h)) || memcmp(h.magic, SNAP_MAGIC, sizeof(SNAP_MAGIC)) ||
        h.version != SNAP_VERSION || h.node_size != sizeof(node_t) || !h.nodes || h.nodes > TREE_MAX_BYTES / sizeof(node_t) ||
        !h.pool || h.pool > TREE_MAX_BYTES || (uint64_t)st.st_size != sizeof(h) + h.nodes * sizeof(node_t) + h.pool)
        goto bad;
    r.nodes = malloc(h.nodes * sizeof(node_t));
    r.pool = malloc(h.pool);
    if (!r.nodes || !r.pool || read_all(fd, r.nodes, h.nodes * sizeof(node_t)) || read_all(fd, r.pool, h.pool))
        goto bad;
    r.n = r.cap = (uint32_t)h.nodes;
    r.pool_len = r.pool_cap = h.pool;
    r.time = h.time;
    r.duration_ms = h.duration_ms;
    if (!valid(&r))
        goto bad;
    for (uint32_t i = 0; i < r.n; i++)
        r.errors += r.nodes[i].err != 0;
    close(fd);
    *t = r;
    return 0;
bad:
    close(fd);
    tree_free(&r);
    return -1;
}
```

```js
/* SPDX-License-Identifier: GPL-3.0-or-later
 * Copyright (C) 2026 gasb07
 * Squarified treemap (Bruls, Huizing, van Wijk) and its drawing on a canvas.
 * ES5: it also runs in the browser of older firmwares. */
var DSTreemap = (function () {
  /* Worst aspect ratio of a row of areas laid along a side. */
  function worst(row, sum, side) {
    var mx = 0, mn = Infinity, i;
    for (i = 0; i < row.length; i++) {
      if (row[i] > mx) mx = row[i];
      if (row[i] < mn) mn = row[i];
    }
    var s2 = sum * sum, w2 = side * side;
    return Math.max(w2 * mx / s2, s2 / (w2 * mn));
  }

  /* Cells for values inside x, y, w, h: [{i, x, y, w, h}], i the index in values.
   * Largest first gives the squarest cells. Values <= 0 get no cell. */
  function squarify(values, x, y, w, h) {
    var out = [], items = [], total = 0, i;
    for (i = 0; i < values.length; i++) {
      if (values[i] > 0) { items.push(i); total += values[i]; }
    }
    if (!items.length || w <= 0 || h <= 0) return out;
    var scale = w * h / total, k = 0;
    while (k < items.length) {
      var side = Math.min(w, h), row = [values[items[k]] * scale], sum = row[0], end = k + 1;
      while (end < items.length) {
        var a = values[items[end]] * scale, next = row.concat([a]);
        if (worst(next, sum + a, side) > worst(row, sum, side)) break;
        row = next;
        sum += a;
        end++;
      }
      var thick = sum / side, pos = 0, j;
      for (j = 0; j < row.length; j++) {
        var len = row[j] / thick;
        if (w >= h) out.push({ i: items[k + j], x: x, y: y + pos, w: thick, h: len });
        else out.push({ i: items[k + j], x: x + pos, y: y, w: len, h: thick });
        pos += len;
      }
      if (w >= h) { x += thick; w -= thick; } else { y += thick; h -= thick; }
      k = end;
    }
    return out;
  }

  var HUES = [210, 30, 120, 280, 0, 180, 60, 330, 150, 250, 90, 15];

  function shade(hue, level) {
    return 'hsl(' + hue + ',55%,' + Math.min(28 + level * 9, 64) + '%)';
  }

  function fit(ctx, text, width) {
    if (ctx.measureText(text).width <= width) return text;
    while (text.length > 1 && ctx.measureText(text + '…').width > width) text = text.slice(0, -1);
    return text + '…';
  }

  /* Draws map (the JSON of /api/map) on canvas, with the cell of selectedId outlined.
   * Returns the cells for hit(), parents before their children. */
  function draw(canvas, map, selectedId) {
    var ctx = canvas.getContext('2d'), cells = [], sel = null;
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    ctx.font = '11px sans-serif';
    ctx.textBaseline = 'top';
    function walk(node, x, y, w, h, level, hue) {
      var cell = { node: node, x: x, y: y, w: w, h: h }, kids = node.c || [], i;
      cells.push(cell);
      if (node.id === selectedId) sel = cell;
      ctx.fillStyle = node.o ? '#4a4f57' : shade(hue, level);
      ctx.fillRect(x, y, w, h);
      ctx.strokeStyle = '#0e1116';
      ctx.lineWidth = 1;
      ctx.strokeRect(x + 0.5, y + 0.5, Math.max(w - 1, 0), Math.max(h - 1, 0));
      var head = kids.length && w > 30 && h > 30 ? 14 : 0;
      if (w > 40 && h > 14) {
        ctx.fillStyle = '#ffffff';
        ctx.fillText(fit(ctx, node.o ? node.k + ' others' : node.n, w - 6), x + 3, y + 2);
      }
      if (!kids.length || w < 6 || h < 6 + head) return;
      var vals = [];
      for (i = 0; i < kids.length; i++) vals.push(kids[i].s);
      var r = squarify(vals, x + 2, y + head + 1, w - 4, h - head - 3);
      for (i = 0; i < r.length; i++)
        walk(kids[r[i].i], r[i].x, r[i].y, r[i].w, r[i].h, level + 1, level === 0 ? HUES[r[i].i % HUES.length] : hue);
    }
    walk(map, 0, 0, canvas.width, canvas.height, 0, 210);
    if (sel) {
      ctx.strokeStyle = '#ffd400';
      ctx.lineWidth = 2;
      ctx.strokeRect(sel.x + 1, sel.y + 1, Math.max(sel.w - 2, 0), Math.max(sel.h - 2, 0));
    }
    return cells;
  }

  /* The deepest cell at x, y, or null. */
  function hit(cells, x, y) {
    for (var i = cells.length - 1; i >= 0; i--) {
      var c = cells[i];
      if (x >= c.x && y >= c.y && x < c.x + c.w && y < c.y + c.h) return c;
    }
    return null;
  }

  return { squarify: squarify, draw: draw, hit: hit };
})();

if (typeof module !== 'undefined') module.exports = DSTreemap;
```

```js
    var x = new XMLHttpRequest();
    x.open(method, url, true);
    x.onreadystatechange = function () {
      if (x.readyState !== 4) return;
      var body = null;
      try { body = JSON.parse(x.responseText); } catch (e) { body = null; }
      cb(x.status, body);
    };
    x.send(null);
  }

  function fmt(n) {
    var u = ['B', 'KB', 'MB', 'GB', 'TB'], i = 0;
    while (n >= 1024 && i < u.length - 1) { n /= 1024; i++; }
    return (i ? n.toFixed(1) : String(n)) + ' ' + u[i];
  }

  function esc(s) {
    return String(s).replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
  }

  function api(path, id, extra) { return '/api/' + path + '?id=' + id + '&gen=' + gen + extra; }

  /* --- status and scan --- */

  function poll(ms) { clearTimeout(timer); timer = setTimeout(status, ms); }

  function status() {
    req('GET', '/api/status', function (code, s) {
      if (code !== 200 || !s) { $('state').textContent = 'Panel not reachable'; poll(3000); return; }
      scanning = s.state === 'scanning';
      $('scan').textContent = scanning ? 'Cancel' : 'Scan';
      if (scanning) $('state').textContent = 'Scanning: ' + s.entries + ' entries. ' + s.path;
      else if (s.has_tree) $('state').textContent = 'Last scan ' + new Date(s.time * 1000).toLocaleString() +
        ' (' + Math.round(s.duration_ms / 1000) + ' s)' + (s.message ? '. ' + s.message : '');
      else $('state').textContent = s.message || 'No scan yet. Press Scan.';
      $('totals').textContent = s.has_tree ? fmt(s.size) + ' in ' + s.files + ' files and ' + s.dirs + ' folders' +
        (s.errors ? ', ' + s.errors + ' not readable' : '') : '';
      if (s.has_tree && s.gen !== gen) { gen = s.gen; reload(); }
      if (scanning) poll(1000);
    });
  }

  $('scan').onclick = function () {
    req('POST', scanning ? '/api/scan/cancel' : '/api/scan', function () { poll(300); });
  };

  /* --- tree --- */

  function makeRow(n, depth, parentSize) {
    var r = document.createElement('div'), dir = n.type === 'dir' && !n.err && !n.others;
    var pct = parentSize > 0 ? n.size * 100 / parentSize : 100;
    var name = n.others ? n.count + ' others' : n.name;
    if (n.type === 'skip') name += ' (not scanned)';
    if (n.err) name += ' (not readable)';
    r.className = 'row';
    r.tabIndex = 0;
    r.setAttribute('data-id', n.others ? '' : n.id);
    r.setAttribute('data-depth', depth);
    r.setAttribute('data-dir', dir ? '1' : '');
    r.innerHTML = '<span class="tw" style="padding-left:' + depth * 14 + 'px">' + (dir ? '&#9656;' : '') + '</span>' +
      '<span class="nm">' + esc(name) + '</span>' +
      '<span class="bar"><span style="width:' + pct.toFixed(1) + '%"></span></span>' +
      '<span class="sz">' + fmt(n.size) + '</span>' +
      '<span class="pc">' + pct.toFixed(1) + '%</span>' +
      '<span class="it">' + (n.type === 'dir' ? n.files + n.dirs : '') + '</span>';
    return r;
  }

  function rowOf(el) {
    while (el && el !== $('tree')) {
      if (el.className && el.className.indexOf('row') === 0) return el;
      el = el.parentNode;
    }
    return null;
  }

  function rowById(id) { return $('tree').querySelector('[data-id="' + id + '"]'); }
  function isOpen(row) { return row.getAttribute('data-open') === '1'; }

  function collapse(row) {
    var d = +row.getAttribute('data-depth'), r = row.nextSibling;
    while (r && +r.getAttribute('data-depth') > d) {
      var next = r.nextSibling;
      r.parentNode.removeChild(r);
      r = next;
    }
    row.setAttribute('data-open', '');
    row.firstChild.innerHTML = '&#9656;';
  }

  function expand(row, done) {
    if (!row.getAttribute('data-dir') || isOpen(row) || row.getAttribute('data-busy')) { if (done) done(); return; }
    row.setAttribute('data-busy', '1');
    var d = +row.getAttribute('data-depth');
    req('GET', api('node', row.getAttribute('data-id'), '&limit=200'), function (code, n) {
      row.setAttribute('data-busy', '');
      if (code === 409) { status(); return; }
      if (code !== 200 || !row.parentNode) return;
      var frag = document.createDocumentFragment(), i;
      for (i = 0; i < n.children.length; i++) frag.appendChild(makeRow(n.children[i], d + 1, n.size));
      if (n.others.count)
        frag.appendChild(makeRow({ others: 1, count: n.others.count, size: n.others.size, type: 'file' }, d + 1, n.size));
      row.parentNode.insertBefore(frag, row.nextSibling);
      row.setAttribute('data-open', '1');
      row.firstChild.innerHTML = '&#9662;';
      if (done) done();
    });
  }

  function toggle(row) { if (isOpen(row)) collapse(row); else expand(row); }

  function mark(row) {
    var prev = $('tree').querySelector('.sel');
    if (prev) prev.className = 'row';
    row.className = 'row sel';
  }

  function select(row) {
    mark(row);
    var id = row.getAttribute('data-id');
    selected = id === '' ? -1 : +id;
    info(selected);
    drawMap();
  }

  /* Click selects; a second click (X on the controller) on the selected folder opens it. */
  $('tree').onclick = function (e) {
    var row = rowOf(e.target || e.srcElement);
    if (!row) return;
    if (row.className === 'row sel' || (e.target || e.srcElement).className === 'tw') toggle(row);
    select(row);
  };

  $('tree').onkeydown = function (e) {
    var row = rowOf(e.target || e.srcElement), k = e.keyCode;
    if (!row) return;
    if (k === 13) toggle(row);
    else if (k === 39) expand(row);
    else if (k === 37) { if (isOpen(row)) collapse(row); }
    else if (k === 40 && row.nextSibling) { row.nextSibling.focus(); select(row.nextSibling); }
    else if (k === 38 && row.previousSibling) { row.previousSibling.focus(); select(row.previousSibling); }
    else return;
    if (e.preventDefault) e.preventDefault();
  };

  function reload() {
    $('tree').innerHTML = '';
    selected = -1;
    mapRoot = 0;
    info(-1);
    req('GET', api('node', 0, '&limit=0'), function (code, n) {
      if (code === 409) { status(); return; }
      if (code !== 200) return;
      var row = makeRow(n, 0, n.size);
      $('tree').appendChild(row);
      expand(row);
      enterMap(0);
    });
  }

  /* Opens the folders down to id and selects its row (when it is not under "others"). */
  function revealInTree(id) {
    req('GET', api('node', id, '&limit=0'), function (code, n) {
      if (code !== 200) return;
      var chain = n.ancestors, i = 0;
      (function next() {
        if (i < chain.length) {
          var r = rowById(chain[i++].id);
          if (r) expand(r, next);
          return;
        }
        var row = rowById(id);
        if (row) { mark(row); if (row.scrollIntoView) row.scrollIntoView(false); }
      })();
    });
  }

  function info(id) {
    if (id < 0) { $('info').innerHTML = ''; return; }
    req('GET', api('node', id, '&limit=0'), function (code, n) {
      if (code !== 200 || id !== selected) return;
      $('info').innerHTML = esc(n.path) + ' &middot; ' + fmt(n.size) +
        (n.type === 'dir' ? ' &middot; ' + n.files + ' files, ' + n.dirs + ' folders <button id="open">Show in map</button>' : '');
      var b = $('open');
      if (b) b.onclick = function () { enterMap(n.id); };
    });
  }

  /* --- treemap --- */

  function enterMap(id) {
    req('GET', api('node', id, '&limit=0'), function (code, n) {
      if (code !== 200) return;
      mapRoot = id;
      var all = n.ancestors.concat([{ id: n.id, name: n.name }]), html = '', i;
      for (i = 0; i < all.length; i++)
        html += (i ? ' / ' : '') + '<a href="#" data-id="' + all[i].id + '">' + esc(all[i].name) + '</a>';
      $('crumbs').innerHTML = html;
      req('GET', api('map', id, '&depth=3'), function (c2, m) {
        if (c2 === 409) { status(); return; }
        if (c2 !== 200) return;
        mapData = m;
        drawMap();
      });
    });
  }

  $('crumbs').onclick = function (e) {
    var a = e.target || e.srcElement, id = a.getAttribute && a.getAttribute('data-id');
    if (id !== null && id !== undefined && id !== '') enterMap(+id);
    if (e.preventDefault) e.preventDefault();
  };

  function drawMap() {
    var c = $('map');
    if (!mapData) return;
    c.width = c.clientWidth || 600;
    c.height = c.clientHeight || 320;
    cells = DSTreemap.draw(c, mapData, selected);
  }

  function cellAt(e) {
    var r = $('map').getBoundingClientRect();
    var cell = DSTreemap.hit(cells, e.clientX - r.left, e.clientY - r.top);
    return cell && !cell.node.o ? cell : null;
  }

  $('map').onclick = function (e) {
    var cell = cellAt(e);
    if (!cell) return;
    selected = cell.node.id;
    info(selected);
    revealInTree(selected);
    drawMap();
  };

  $('map').ondblclick = function (e) {
    var cell = cellAt(e);
    if (cell && cell.node.t === 'dir' && cell.node.id !== mapRoot) enterMap(cell.node.id);
  };

  $('map').onmousemove = function (e) {
    var cell = cellAt(e);
    $('map').title = cell ? cell.node.n + ' · ' + fmt(cell.node.s) : '';
  };

  window.onresize = drawMap;
  status();
})();
```

```c
/* SPDX-License-Identifier: GPL-3.0-or-later

#include <fcntl.h>
#include <stdlib.h>
#include <string.h>

#include <unistd.h>

#include "check.h"

static char g_resp[1 << 20];

static const char *ask(const char *req) {
    int sv[2];
    if (socketpair(AF_UNIX, SOCK_STREAM, 0, sv))
        return "";
    if (write(sv[0], req, strlen(req)) < 0)
        perror("write");
    shutdown(sv[0], SHUT_WR);
    web_handle(sv[1]);
    size_t n = 0;
    ssize_t r;
    while (n < sizeof(g_resp) - 1 && (r = read(sv[0], g_resp + n, sizeof(g_resp) - 1 - n)) > 0)
        n += (size_t)r;
    g_resp[n] = 0;
    close(sv[0]);
    return g_resp;
}

static const char *get(const char *path) {
    char req[600];
    snprintf(req, sizeof(req), "GET %s HTTP/1.1\r\nHost: x\r\n\r\n", path);
    return ask(req);
}

static const char *post(const char *path) {
    char req[600];
    snprintf(req, sizeof(req), "POST %s HTTP/1.1\r\nHost: x\r\nContent-Length: 0\r\n\r\n", path);
    return ask(req);
}

static int code(const char *resp, const char *c) {
    char want[32];
    snprintf(want, sizeof(want), "HTTP/1.1 %s", c);
    return !strncmp(resp, want, strlen(want));
}

int main(void) {
    const char *tmp = getenv("TEST_TMP");
    char root[1024], p[1200], snap[1200];
    snprintf(root, sizeof(root), "%s/http.XXXXXX", tmp ? tmp : "/tmp");
    if (!mkdtemp(root))
        return 1;
    /* 600 files: the scan passes two pauses, so requests meet it running */
    for (int i = 0; i < 600; i++) {
        snprintf(p, sizeof(p), "%s/f%03d", root, i);
        int fd = open(p, O_WRONLY | O_CREAT, 0644);
        if (fd >= 0) {
            if (ftruncate(fd, i + 1))
                perror("ftruncate");
            close(fd);
        }
    }
    snprintf(snap, sizeof(snap), "%s.bin", root);

    ds_config_t cfg = {0};
    cfg.root = root;
    cfg.snap_path = snap;
    cfg.pause_us = 100000;
    ds_init(&cfg);

    CHECK(code(get("/"), "200") && strstr(g_resp, "<title>PS5 DirStat</title>"));
    CHECK(code(get("/legacy"), "200") && strstr(g_resp, "older firmwares"));
    CHECK(code(get("/app.js"), "200") && strstr(g_resp, "javascript"));

    CHECK(code(get("/nope"), "404"));
    CHECK(code(ask("GARBAGE\r\n\r\n"), "400"));

    CHECK(code(post("/api/scan"), "200"));
    CHECK(code(post("/api/scan"), "409"));
    CHECK(code(get("/api/status"), "200") && strstr(g_resp, "\"state\":\"scanning\""));
    ds_wait();
    CHECK(code(get("/api/status"), "200") && strstr(g_resp, "\"gen\":2") && strstr(g_resp, "\"files\":600"));
    struct stat st;
    CHECK(stat(snap, &st) == 0);

    CHECK(strstr(g_resp, "\"name\":\"f599\",\"size\":600") && strstr(g_resp, "\"others\":{\"count\":597"));
```

```c
#include "state.h"

#include <pthread.h>
#include <sched.h>
#include <stdio.h>
#include <string.h>

#include "scan.h"
#include "snap.h"
#include "tree.h"

#define MAP_MAX_NODES 5000

static ds_config_t g_cfg;
static pthread_mutex_t g_mu = PTHREAD_MUTEX_INITIALIZER;
static tree_t g_tree;      /* the tree the panel shows; replaced only by the scan thread */
static int g_have;         /* g_tree holds a tree */
static int g_scanning;
static int g_joinable;     /* main thread only */
static volatile int g_cancel;
static uint32_t g_gen = 1; /* changes with every new tree */
static uint64_t g_entries;
static char g_path[512], g_msg[200];
static pthread_t g_th;

static void say(const char *msg) {
    printf("[scan] %s\n", msg);
    if (g_cfg.notify)
        g_cfg.notify(msg);
}

static void size_text(uint64_t n, char *out, size_t cap) {
    static const char *const u[] = {"B", "KB", "MB", "GB", "TB"};
    double v = (double)n;
    int i = 0;
    while (v >= 1024 && i < 4) {
        v /= 1024;
        i++;
    }
    snprintf(out, cap, i ? "%.1f %s" : "%.0f %s", v, u[i]);
}

void ds_init(const ds_config_t *cfg) {
    g_cfg = *cfg;
    tree_t t;
    if (cfg->snap_path && !snap_read(cfg->snap_path, &t)) {
        g_tree = t;
        g_have = 1;
        printf("[snap] loaded %u entries from %s\n", t.n, cfg->snap_path);
    } else if (cfg->snap_path) {
        printf("[snap] no valid snapshot at %s\n", cfg->snap_path);
    }
}

static void progress(void *ctx, uint64_t entries, const char *path) {
    (void)ctx;
    pthread_mutex_lock(&g_mu);
    g_entries = entries;
    snprintf(g_path, sizeof(g_path), "%s", path);
    pthread_mutex_unlock(&g_mu);
}

static void *scan_thread(void *arg) {
    (void)arg;
    struct sched_param sp;
    memset(&sp, 0, sizeof(sp));
    sp.sched_priority = sched_get_priority_min(SCHED_OTHER);
    int prc = pthread_setschedparam(pthread_self(), SCHED_OTHER, &sp);
    printf("[scan] thread priority %d (rc %d)\n", sp.sched_priority, prc);

    char **skip = NULL;
    int nskip = g_cfg.skip_list ? g_cfg.skip_list(&skip) : 0;
    tree_t t;
    memset(&t, 0, sizeof(t));
    t.max_bytes = g_cfg.max_bytes;
    scan_opt_t o;
    memset(&o, 0, sizeof(o));
    o.root = g_cfg.root;
    o.skip = (const char *const *)skip;
    o.nskip = nskip;
    o.cancel = &g_cancel;
    o.progress = progress;
    o.pause_us = g_cfg.pause_us;
    int rc = scan_run(&o, &t);
    if (g_cfg.skip_free)
        g_cfg.skip_free(skip, nskip);

    char msg[200], size[32];
    if (rc == SCAN_OK) {
        tree_t old;
        pthread_mutex_lock(&g_mu);
        old = g_tree;
        g_tree = t;
        g_have = 1;
        g_gen++;
        pthread_mutex_unlock(&g_mu);
        if (old.nodes)
            tree_free(&old);
        /* no other thread changes g_tree while g_scanning is set */
        if (g_cfg.snap_path && snap_write(g_cfg.snap_path, &g_tree))
            printf("[snap] could not write %s\n", g_cfg.snap_path);
        size_text(g_tree.nodes[0].size, size, sizeof(size));
        snprintf(msg, sizeof(msg), "Scan done: %s in %u files, %llu s", size, g_tree.nodes[0].files,
                 (unsigned long long)(g_tree.duration_ms / 1000));
    } else {
        uint64_t read_n = t.n;
        tree_free(&t);
        if (rc == SCAN_CANCELLED)
            snprintf(msg, sizeof(msg), "Scan cancelled");
        else
            snprintf(msg, sizeof(msg), "Scan stopped: not enough memory (%llu entries read)", (unsigned long long)read_n);
    }
    pthread_mutex_lock(&g_mu);
    g_scanning = 0;
    snprintf(g_msg, sizeof(g_msg), "%s", msg);
    pthread_mutex_unlock(&g_mu);
    say(msg);
    return NULL;
}

int ds_scan_start(void) {
    pthread_mutex_lock(&g_mu);
    if (g_scanning) {
        pthread_mutex_unlock(&g_mu);
        return -1;
    }
    g_scanning = 1;
    g_cancel = 0;
    g_entries = 0;
    g_path[0] = 0;
    g_msg[0] = 0;
    pthread_mutex_unlock(&g_mu);
    ds_wait(); /* the previous thread has ended: release it */
    say("Scan started");
    if (pthread_create(&g_th, NULL, scan_thread, NULL)) {
        pthread_mutex_lock(&g_mu);
        g_scanning = 0;
        snprintf(g_msg, sizeof(g_msg), "Could not start the scan");
        pthread_mutex_unlock(&g_mu);
        return -1;
    }
    g_joinable = 1;
    return 0;
}

void ds_scan_cancel(void) { g_cancel = 1; }

void ds_wait(void) {
    if (g_joinable) {
        pthread_join(g_th, NULL);
        g_joinable = 0;
    }
}

void ds_status_json(buf_t *out) {
    pthread_mutex_lock(&g_mu);
    buf_printf(out, "{\"state\":\"%s\",\"gen\":%u,\"has_tree\":%s", g_scanning ? "scanning" : "idle", g_gen,
               g_have ? "true" : "false");
    if (g_have) {
        const node_t *r = &g_tree.nodes[0];
        buf_printf(out, ",\"time\":%lld,\"duration_ms\":%llu,\"size\":%llu,\"files\":%u,\"dirs\":%u,\"errors\":%u",
                   (long long)g_tree.time, (unsigned long long)g_tree.duration_ms, (unsigned long long)r->size, r->files,
                   r->dirs, g_tree.errors);
    }
    buf_printf(out, ",\"entries\":%llu,\"path\":", (unsigned long long)g_entries);
    buf_json_str(out, g_path);
    BUF_LIT(out, ",\"message\":");
    buf_json_str(out, g_msg);
    BUF_LIT(out, "}");
    pthread_mutex_unlock(&g_mu);
}

static int check_id(uint32_t id, uint32_t gen) {
    if (!g_have)
        return 503;
    if (gen != g_gen)
        return 409;
    return id < g_tree.n ? 200 : 404;
}

int ds_node_json(uint32_t id, uint32_t gen, uint32_t limit, buf_t *out) {
    pthread_mutex_lock(&g_mu);
    int code = check_id(id, gen);
    if (code == 200)
        tree_node_json(&g_tree, id, limit, out);
    pthread_mutex_unlock(&g_mu);
    return code;
}

int ds_map_json(uint32_t id, uint32_t gen, int depth, buf_t *out) {
    pthread_mutex_lock(&g_mu);
    int code = check_id(id, gen);
    if (code == 200 && tree_map_json(&g_tree, id, depth, MAP_MAX_NODES, out))
        code = 503;
    pthread_mutex_unlock(&g_mu);
    return code;
}
```

```c
#include "web.h"

#include <netinet/in.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/socket.h>
#include <sys/time.h>

#include "state.h"

#define JSON "application/json; charset=utf-8"
#define JS "application/javascript; charset=utf-8"
#define HTML "text/html; charset=utf-8"

int web_listen(void) {
    int s = socket(AF_INET, SOCK_STREAM, 0), one = 1;
    struct sockaddr_in a;
    memset(&a, 0, sizeof(a));
    a.sin_family = AF_INET;
    a.sin_port = htons(WEB_PORT);
    a.sin_addr.s_addr = htonl(INADDR_ANY);
    if (s < 0)
        return -1;
    setsockopt(s, SOL_SOCKET, SO_REUSEADDR, &one, sizeof(one));
    if (bind(s, (struct sockaddr *)&a, sizeof(a)) || listen(s, 8)) {
        close(s);
        return -1;
    }
    return s;
}

static void send_all(int fd, const void *p, size_t n) {
    const char *c = p;
    while (n) {
        ssize_t w = write(fd, c, n);
        if (w <= 0)
            return;
        c += w;
        n -= (size_t)w;
    }
}

static const char *status_text(int code) {
    switch (code) {
    case 200: return "200 OK";
    case 404: return "404 Not Found";
    case 409: return "409 Conflict";
    case 503: return "503 Service Unavailable";
    default: return "400 Bad Request";
    }
}

static void reply(int fd, int code, const char *type, const void *body, size_t len) {
    char head[256];
    int n = snprintf(head, sizeof(head),
                     "HTTP/1.1 %s\r\nContent-Type: %s\r\nContent-Length: %zu\r\nCache-Control: no-store\r\n"
                     "Connection: close\r\n\r\n",
                     status_text(code), type, len);
    send_all(fd, head, (size_t)n);
    send_all(fd, body, len);
}

static void reply_buf(int fd, int code, buf_t *b) {
    reply(fd, code, JSON, b->data ? (const char *)b->data : "", b->len);
    buf_free(b);
}

static void reply_msg(int fd, int code, const char *msg) {
    buf_t b = {0};
    buf_printf(&b, "{\"ok\":%s,\"message\":", code == 200 ? "true" : "false");
    buf_json_str(&b, msg);
    BUF_LIT(&b, "}");
    reply_buf(fd, code, &b);
}

/* Number after key= in the query of path; def when missing or not a number. */
static unsigned long qnum(const char *path, const char *key, unsigned long def) {
    const char *p = strchr(path, '?');
    size_t kl = strlen(key);
    while (p) {
        p++;
        if (!strncmp(p, key, kl) && p[kl] == '=') {
            if (p[kl + 1] < '0' || p[kl + 1] > '9')
                return def;
            return strtoul(p + kl + 1, NULL, 10);
        }
        p = strchr(p, '&');
    }
    return def;
}

static unsigned long clamp(unsigned long v, unsigned long lo, unsigned long hi) { return v < lo ? lo : v > hi ? hi : v; }

static const char *error_text(int code) {
    return code == 409 ? "The scan changed: reload" : code == 404 ? "No such entry" : "No scan yet";
}

void web_serve(int listen_fd) {
    int fd = accept(listen_fd, NULL, NULL);
    if (fd >= 0)
        web_handle(fd);
}

void web_handle(int fd) {
    struct timeval tv = {5, 0};
    setsockopt(fd, SOL_SOCKET, SO_RCVTIMEO, &tv, sizeof(tv));
    char req[4096], method[8] = "", path[512] = "", route[512];
    ssize_t n = read(fd, req, sizeof(req) - 1);
    if (n <= 0) {
        close(fd);
        return;
    }
    req[n] = 0;
    if (sscanf(req, "%7s %511s", method, path) != 2) {
        reply_msg(fd, 400, "Bad request");
        close(fd);
        return;
    }
    size_t rl = strcspn(path, "?");
    memcpy(route, path, rl);
    route[rl] = 0;
    int get = !strcmp(method, "GET"), post = !strcmp(method, "POST");
    /* a missing, invalid or too large id never matches a node */
    unsigned long id = qnum(path, "id", 0xffffffffUL), gen = qnum(path, "gen", 0);
    if (id > 0xffffffffUL)
        id = 0xffffffffUL;

    if (get && !strcmp(route, "/"))
        reply(fd, 200, HTML, index_html, sizeof(index_html));
    else if (get && !strcmp(route, "/legacy"))
        reply(fd, 200, HTML, legacy_html, sizeof(legacy_html));
    else if (get && !strcmp(route, "/app.js"))
        reply(fd, 200, JS, app_js, sizeof(app_js));
    else if (get && !strcmp(route, "/treemap.js"))
        reply(fd, 200, JS, treemap_js, sizeof(treemap_js));
    else if (get && !strcmp(route, "/api/status")) {
        buf_t b = {0};
        ds_status_json(&b);
        reply_buf(fd, 200, &b);
    } else if (post && !strcmp(route, "/api/scan")) {
        int busy = ds_scan_start(); /* post */
        reply_msg(fd, busy ? 409 : 200, busy ? "A scan is already running" : "Scan started");
    } else if (post && !strcmp(route, "/api/scan/cancel")) {
        ds_scan_cancel(); /* post */
        reply_msg(fd, 200, "Cancelling the scan");
    } else if (get && !strcmp(route, "/api/node")) {
        buf_t b = {0};
        int code = ds_node_json((uint32_t)id, (uint32_t)gen, (uint32_t)clamp(qnum(path, "limit", 200), 0, 1000), &b);
        if (code == 200)
            reply_buf(fd, 200, &b);
        else
            reply_msg(fd, code, error_text(code));
    } else if (get && !strcmp(route, "/api/map")) {
        buf_t b = {0};
        int code = ds_map_json((uint32_t)id, (uint32_t)gen, (int)clamp(qnum(path, "depth", 3), 1, 6), &b);
        if (code == 200)
            reply_buf(fd, 200, &b);
        else
            reply_msg(fd, code, error_text(code));
    } else {
        reply(fd, 404, "text/plain", "not found\n", 10);
    }
    close(fd);
}
```

```c
        return 0;
    uint8_t *tmp = malloc(size);
    int same = tmp && read(fd, tmp, size) == (ssize_t)size && !memcmp(tmp, data, size);
    free(tmp);
    close(fd);
    return same;
}

/* --- firmware: how the Media tab shortcut is registered (same rule as PS4Mount) --- */

typedef int (*title_dir_fn)(const char *title_id, const char *dir, void *reserved);
static title_dir_fn g_title_dir;
static int g_reg_mode = REG_ALL;
static char g_fw_text[16] = "unknown";

static void check_firmware(void) {
    uint32_t fw = kernel_get_fw_version();
    unsigned major, minor;
    fw_decode(fw, &major, &minor);
    fw_text(fw, g_fw_text, sizeof(g_fw_text));
    /* looked up at runtime: linking it would stop the payload from loading where it is gone */
    uint32_t h = 0;
    if (!kernel_dynlib_handle(getpid(), "libSceAppInstUtil.sprx", &h))
        g_title_dir = (title_dir_fn)kernel_dynlib_dlsym(getpid(), h, "sceAppInstUtilAppInstallTitleDir");
    g_reg_mode = fw_reg_mode(major, g_title_dir != NULL);
    printf("[main] firmware %s (0x%08x), registration mode %d\n", g_fw_text, fw, g_reg_mode);
}

static int register_call(const char *tid) {
    if (g_reg_mode == REG_TITLEDIR) {
        int rc = g_title_dir(tid, "/user/app/", NULL);
        return rc == (int)0x80990002 ? 0 : rc; /* already known */
    }
    return sceAppInstUtilAppInstallAll(NULL);
}

/* --- Media tab shortcut (category 65536 + deeplinkUri) --- */

#define PANEL_ID "DSTT00001"
static const char k_panel_param[] =
    "{\n"
    "    \"titleId\": \"" PANEL_ID "\",\n"
    "    \"applicationCategoryType\": 65536,\n"
    "    \"deeplinkUri\": \"http://127.0.0.1:8771/\",\n"
    "    \"localizedParameters\": {\n"
    "        \"defaultLanguage\": \"en-US\",\n"
    "        \"en-US\": {\n"
    "            \"titleName\": \"PS5 DirStat\"\n"
    "        }\n"
    "    }\n"
    "}\n";

/* Installs the shortcut when it is missing or out of date. */
static void install_panel_shortcut(void) {
    const char *param = "/user/app/" PANEL_ID "/sce_sys/param.json", *icon = "/user/app/" PANEL_ID "/sce_sys/icon0.png";
    int present = db_is_registered(PANEL_ID);
    int same_param = same_file(param, k_panel_param, sizeof(k_panel_param) - 1);
    int same_icon = same_file(icon, icon0_png, sizeof(icon0_png));
    printf("[panel] present=%d param=%d icon=%d\n", present, same_param, same_icon);
    if (present && same_param && same_icon)
        return;
    mkdirs("/user/app/" PANEL_ID "/sce_sys", 0755);
    if (write_file(param, k_panel_param, sizeof(k_panel_param) - 1, 0644) ||
        write_file(icon, icon0_png, sizeof(icon0_png), 0644)) {
        printf("[panel] shortcut files: %s\n", strerror(errno));
        return;
    }
    int rc = register_call(PANEL_ID);
    printf("[panel] shortcut install rc=0x%08x\n", rc);
    if (!rc)
        notify("PS5 DirStat added to the Media tab");
}

/* --- single instance and listening sockets --- */

static int single_instance(void) {
    int s = socket(AF_INET, SOCK_STREAM, 0);
    struct sockaddr_in a;
    memset(&a, 0, sizeof(a));
    a.sin_family = AF_INET;
    a.sin_port = htons(LOCK_PORT);
    a.sin_addr.s_addr = htonl(INADDR_LOOPBACK);
    if (s < 0 || bind(s, (struct sockaddr *)&a, sizeof(a)) || listen(s, 1)) {
        if (s >= 0)
            close(s);
        return -1;
    }
    return s;
}

/* Rest mode closes the sockets of payloads: a socket that stopped listening is opened again. */
static int still_listening(int s) {
    int on = 0;
    socklen_t n = sizeof(on);
    return s >= 0 && !getsockopt(s, SOL_SOCKET, SO_ACCEPTCONN, &on, &n) && on;
}

int main(void) {
    int lock = single_instance();
    if (lock < 0) {
        printf(VERSION " already running\n");
        return 0;
    }
    sceUserServiceInitialize(0);
    sceAppInstUtilInitialize();
    mkdirs(STATE_DIR, 0777);
    if (!log_start(STATE_DIR "/log.txt"))
        atexit(log_stop);
    setvbuf(stdout, NULL, _IOLBF, 0);
    signal(SIGPIPE, SIG_IGN);
    printf("[main] " VERSION " starting\n");
    check_firmware();
    if (g_reg_mode != REG_NONE)
        install_panel_shortcut();

    ds_config_t cfg;
    memset(&cfg, 0, sizeof(cfg));
    cfg.root = "/";
    cfg.snap_path = STATE_DIR "/last.bin";
    cfg.pause_us = 1000;
    cfg.max_bytes = TREE_MAX_BYTES;
    cfg.skip_list = mounts_skip_list;
    cfg.skip_free = mounts_free;
    cfg.notify = scan_note;
    ds_init(&cfg);

    int web = web_listen();
    notify(web >= 0 ? VERSION " running. Panel in the Media tab or http://<PS5 IP>:8771"
                    : VERSION " running (panel unavailable)");
    for (;;) {
        if (!still_listening(lock)) {
            close(lock);
            if ((lock = single_instance()) < 0) {
                notify(VERSION " stopped: another PS5 DirStat is running");
                return 0;
            }
        }
        if (!still_listening(web)) {
            if (web >= 0)
                close(web);
            web = web_listen();
            printf("[main] web panel %s\n", web >= 0 ? "listening again" : "unavailable");
        }
        if (web < 0) {
            sleep(1);
            continue;
        }
        fd_set fs;
        FD_ZERO(&fs);
        FD_SET(web, &fs);
        struct timeval tv = {1, 0};
        if (select(web + 1, &fs, NULL, NULL, &tv) > 0)
            web_serve(web);
    }
}
```

```markdown
# PS5 DirStat

See what is using the storage of a jailbroken PS5, like WinDirStat on Windows.

PS5 DirStat scans the console file system in the background, at low priority, and shows the
result in a web panel: a folder tree sorted by size, with a bar on each row, and a treemap where
every rectangle is a folder or file and its area is its size. It only reads: nothing is deleted
or moved.

## Requirements

- A jailbroken PS5 with an ELF loader listening on port **9021**.

## Use

1. Send `ps5-dirstat.elf` to the ELF loader.
2. Open **PS5 DirStat** in the **Media** tab, or `http://<PS5 IP>:8771` on a PC or phone on the
   same network.
3. Press **Scan**. A notification shows when the scan starts and when it ends.

The last scan is kept in `/data/ps5-dirstat/last.bin` and shown again the next time the payload
loads. Press **Scan** to update it.

## Panel

- **Tree**: click a row to select it, click it again (or press X) to open the folder. Arrow keys
  also work.
- **Treemap**: click a rectangle to find it in the tree, double click a folder to show it alone,
  and use the path above the map to go back up. **Show in map** opens the selected folder.
- Older firmwares open a simpler version of the same panel automatically (`/legacy`).

## What is not counted

- `/dev`, and mounts that hold no data of their own or repeat other folders (`devfs`, `nullfs`,
  `procfs`, `fdescfs`, `tmpfs`). They are listed as "not scanned".
- Files with several hard links are counted once. Symbolic links are not followed.
- Folders the payload cannot read are listed as "not readable".

## Logs

`/data/ps5-dirstat/log.txt`, including every mount and its type at the start of each scan.

## Build

Requires the [PS5 Payload SDK](https://github.com/ps5-payload-dev/sdk) in `/opt/ps5-payload-sdk`
(or set `PS5_PAYLOAD_SDK`).

    bash build.sh        # build/ps5-dirstat.elf
    bash test/run.sh     # host tests (no console needed)
```
